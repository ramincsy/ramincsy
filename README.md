| **[Sarafchi](https://github.com/ramincsy/Sarafchi)** | Internal **currency-exchange accounting** app: users, balances, trades, rial/USDT deposit & withdraw, bank inquiries. React + Flask + SQL Server. Uses TronGrid for USDT on TRON. Not a public SaaS — it expects an existing `sarafchi-DB`. |
